# 개발 과정 복원

현재 시점에 대화의 코드와 최종 파일을 바탕으로 재구성한 기록입니다.
원래 작업 당시의 커밋이 아니며 날짜는 변경하지 않았습니다.
세부 단계 분할은 복원 시 정리했습니다. 중간 구현은 설명용으로 재구성했으므로 당시 파일과 완전히 같다고 주장하지 않습니다.
기존 main과 원래 커밋 4개는 보존합니다. 게임 실행은 루트 main.py를 사용하세요.
중간 스냅샷은 미완성일 수 있으며 최종 스냅샷은 루트 완성본과 일치시킵니다.

## 복원 단계
1. 복원 기록의 근거와 범위 및 기존 main 보존 명시
2. IDLE 상태 머신과 기존 8프레임 대기 애니메이션 복원
3. SLEEP 상태 및 IDLE에서 SLEEP으로 전환 규칙 복원
4. IDLE에서 5초 경과 시 수면 타이머 동작 복원
5. SPACE 깨우기와 IDLE 타이머 재시작 복원
6. 월드 생성과 main에서 Boy 입력 이벤트 전달 연결 복원
7. 수면 진입 시 첫 프레임 고정 복원
8. 잔디 위에 눕는 회전 렌더링과 위치 보정 복원
9. 좌우를 구분하지 않는 RUN 상태와 시작 및 정지 규칙 복원
10. 방향키 입력과 마지막 입력 방향 선택 복원
11. 방향키 해제 및 양쪽 키를 겹쳐 누르는 경우 복원
12. 경과 시간 기반 일반 달리기와 방향별 달리기 애니메이션 복원
13. 화면 양 끝에서 스프라이트 전체를 보호하는 위치 제한 복원
